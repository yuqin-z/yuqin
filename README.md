# Yuqin Zhong — research portfolio

Static HTML/CSS/JavaScript, suitable for GitHub Pages. This is a local design preview; nothing has been published.

## Preview

Run `node preview.mjs` in this folder and open http://127.0.0.1:8765.
Stop the server with Ctrl+C. You can also open `index.html` directly.

- Homepage: `index.html`
- Section pages: `research.html`, `design.html`, `tools.html`
- About & CV: `cv.html` (all sections from the supplied 18 October 2026 CV, except Skills)
- Original version: `backups/original-2026-10-19/index.html`

## Interactions

On desktop, hovering reveals a panel overview. Click to keep it open, then click again to close. Keyboard users can Tab to a panel, press Enter or Space, and Tab to its section link. Escape closes overviews. Touch users tap to open and close. Without JavaScript, native disclosure controls remain available.

## Content and visuals

The SVGs in `assets/editorial/` are original conceptual placeholder illustrations, not project evidence or research results. Replace these with approved public imagery. The portrait is reused from the original site. No participant data or restricted research images have been added.

Research / Design / Tools are lenses onto the work. Research contains the three named PhD projects and two conference-paper projects. Design contains UNStudio, WOHA and the master’s thesis. Tools contains Move360 and the pedestrian simulation workflow; the agent is excluded from Tools. The CV preserves the agent contribution under research experience, as stated in the source CV. Project-image slots await approved imagery. The original resume PDF is not copied into the site. Published papers link to their DOI or institutional records; the Designing manuscript retains revision-submitted status.

## Backup

The complete original site, including its assets, is preserved under `backups/original-2026-10-19/`. Its three source files were hash-checked against the originals before editing. To restore, copy that folder's `index.html`, `styles.css`, `script.js` and `assets` back to the repository root.

Before publishing, decide whether to keep the backup in the deployed repository. GitHub Pages can serve tracked backup files even when they are not linked from the homepage.
